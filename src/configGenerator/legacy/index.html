Home Assistant package generator

Last opp KNX. Fyll inn fem felt. Last ned YAML.

Generatoren prøver å hente resten fra KNX-filen automatisk. Det du vanligvis bare trenger å legge inn er badstunavn, merchant id og booking-id for felles, privat, aufguss og service. Utstyr som ikke finnes i KNX-filen blir automatisk utelatt fra konfigurasjonen.

Steg 3
